# Toolchain

A **toolchain** is a note under `toolchains/`. It is an ordered combination
of [[tool]] notes. A sentence that says "and then" is already a toolchain.

A wrapper script comes after the order has run by hand. Worked examples:
[[new-integration]] and [[eval-loop]]. Pattern: [[admit]].
